# Roadmap

## v0.1 MVP

- `Win+Q` AutoHotkey v2 hotkey
- Primary monitor capture
- Windows OCR through `Windows.Media.Ocr.OcrEngine`
- Click OCR text block selection
- Copy selected text
- Browser Translate
- Search Web
- Settings file
- Privacy-aware logs
- Install and uninstall scripts

## v0.2 Better Overlay Selection

- Drag-select OCR regions
- Better merged line and paragraph selection
- Multi-monitor coordinate polish
- DPI-scaling validation
- Improved keyboard navigation

## v0.3 Inline Translation

- Inline translation result panel
- Provider configuration UI
- DeepL, OpenAI, Gemini, and LibreTranslate integrations
- Better failure messages for API providers

## v0.4 Local AI Actions

- Local LLM actions through Ollama
- Summarize selected text
- Explain selected text
- Rewrite selected text
- Privacy modes for local-only workflows

## v1.0 Stable Release

- Portable release package
- Signed binaries
- winget package
- Microsoft Store evaluation
- Stable installer and updater
- Accessibility pass
- Full multi-monitor support
